# Tilt Roller

A three.js ball-rolling game for phones. Tilt the phone left/right to steer, tap to jump.
Every start generates a new track with banked berms, jumps, rings of fire, vertical loops,
horizontal spirals, off-camber sections, earthquakes, fog banks and a finish line with flags.

Play: https://lacwuh.github.io/tilt-roller/ (open on the phone, tap START and allow motion access).
Desktop: arrow keys to steer, Space to jump.
